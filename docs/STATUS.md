# Status

2026-11-10. The project starts. It has the governance files and the project standard. It has no source code and no release. [Decision 0001](decisions/0001-build-tools.md) gives the build tools and the dependency rule.

## Plan

The GitHub milestones hold the issues of each release.

| Release | Scope |
|---|---|
| v0.1 | The component catalog and its contract format. Tokens, primitives, cards, action buttons, editable forms and card grids. The contract tests, the accessibility checks and the build check |
| v0.2 | The message envelope with actors and typed parts. A thread for people and agents, with streaming. A refusal of undeclared components. A receipt for each action. The workbench shell and the approval panel for entelos |
| v0.3 | The review panel for groundgate and the evaluation panel for nookku. Typed form edits |
| v0.4 | The offline mode with a queue of pending actions. The knowledge panel for aavanam and the operations panel for koodam. A security review of the action path and the offline queue |
| v0.5 | Deployment of the workbench as a koodam App |
| v1.0 | A stable envelope and catalog contract, with a compatibility statement |
