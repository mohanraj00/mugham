# Guides

Each guide states facts that the code proves. The code of each guide is in [examples/guides/](../../examples/guides/). `tools/browser_check.mjs` runs each guide page and checks the expected results, and `tests/test_guides.py` checks that each code block is part of a checked file.

- [Contracts](contracts.md): what a contract declares, how the kit checks and refuses a fill, the slots, the action binding and an application contract.
- [Assemble a page](assemble.md): the tokens, `define`, a stack and a grid of cards, an action with a receipt, and a thread with an event source.
- [Theme the kit](theme.md): each token, the light and dark themes, forced colors, reduced motion, a second theme, and what a page must not change.
- [For coding agents](agents.md): the rules, the file to read for each task, and a checklist to verify a page.
